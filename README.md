# ⚡ Link-to-QR: The 2026 High-End Generator

Welcome to the future of QR generation. **Link-to-QR** isn't just a utility; it's a high-performance design tool crafted for the modern web. Built with a focus on **Hyper-Modern Minimalist** aesthetics and **Generative UI**, it transforms boring URLs into branding masterpieces.

## 🚀 Key Features
- **✨ Real-time Customization**: Watch your QR code morph and change instantly as you tweak sliders.
- **🎨 Deep Design Control**:
  - **Pattern Morphing**: Choose between Dots, Fluid, Classy, or Square pixels.
  - **Eye Customization**: Independent styling for the 'corner eyes' (Inner & Outer).
  - **Neon Gradients**: Support for linear and radial two-stop gradients across the pattern.
- **🖼️ Premium Branding**:
  - **Smart Logo Masking**: Auto-center your logo with adjustable size and background removal.
  - **SVG Exports**: High-resolution, vector-perfect exports for print and digital.
- **🪄 Magic AI Styles**: One-click presets inspired by industry leaders (Cyberpunk, Apple, Sunset).
- **🎊 Interactive UX**: Glassmorphic UI, smooth Framer Motion transitions, and confetti reveal on export.

## 🛠 Tech Stack
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router & React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **QR Engine**: [qr-code-styling](https://github.com/kozakdenys/qr-code-styling)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏃 Quick Start

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/link-to-qr.git
   cd link-to-qr
   ```

2. Install dependencies (using legacy-peer-deps for React 19 compatibility):
   ```bash
   npm install --legacy-peer-deps
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
